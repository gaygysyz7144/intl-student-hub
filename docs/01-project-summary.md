# Project Summary

## Project
**Intl Student Hub**: a life assistance and sharing platform for new international students in China.

## Background
New international students look for rentals, second-hand items, local information, travel companions and language partners. This information is scattered across chat groups and goes out of date quickly. The platform gathers it in one place and adds a lightweight intelligent matching module.

## Users
- International students (new and returning): publish and search posts, message each other, save favorites
- Senior students: answer help requests
- Administrator: moderate content
